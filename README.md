# Meu Financeiro — interface pública, dados privados

Este repositório contém **somente a interface vazia** do aplicativo Meu Financeiro V6.

## Publicar no GitHub Pages

1. Abra **Settings → Pages** neste repositório.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha **main** e **/(root)**.
4. Clique em **Save**. Quando aparecer **Visit site**, abra o endereço.

O código da interface é público; o site **não possui login**.

## Privacidade

- Não inclua extratos, comprovantes, planilhas, faturas, informações bancárias nem backups neste repositório.
- O aplicativo guarda os lançamentos no `localStorage` do navegador, **sem envio automático ao GitHub**.
- Os dados em `localStorage` **não são criptografados pelo aplicativo**. Proteja o acesso ao aparelho.
- Faça backups protegidos por senha com frequência, salvos em local privado.
- Dados em outro navegador ou aparelho **não são sincronizados**.
- O ChatGPT e as notificações bancárias **ainda não estão integrados** ao aplicativo.

## Primeira utilização

Abra o link do Pages no Safari e importe seu backup **diretamente pelo aplicativo**, sem publicar o arquivo.

> Este é um protótipo de controle financeiro. Confira os cálculos com os valores informados pelos bancos antes de efetuar pagamentos.
